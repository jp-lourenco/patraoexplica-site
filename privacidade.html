Política de privacidade

Atualizada em 20 de outubro de 2026.

Esta política vale para o site O Patrão Explica e para o aplicativo Publicador, usado pelo canal para publicar vídeos e consultar estatísticas nas plataformas YouTube, Instagram, Facebook e TikTok.

Quem usa o aplicativo

O Publicador é uma ferramenta de uso interno do canal. Ele é operado apenas pelo responsável pelo canal, nas contas do próprio canal. Não há cadastro de outras pessoas nem oferta do aplicativo ao público.

Quais dados são acessados

  • Identificação das contas do canal nas plataformas (nome, identificador, nome de usuário).
  • Credenciais de acesso (tokens) concedidas pelas plataformas por meio do login oficial de cada uma.
  • Vídeos, títulos, descrições e legendas que o canal decide publicar.
  • Estatísticas públicas e privadas dos vídeos do canal (visualizações, curtidas, comentários, retenção), para acompanhar o desempenho dos episódios.

Como os dados são usados e guardados

  • Os dados são usados só para publicar os vídeos do canal e acompanhar os números deles.
  • Os tokens ficam guardados no cofre de credenciais do sistema operacional do computador do canal. Não são enviados a terceiros nem a nenhum servidor nosso.
  • As estatísticas ficam em um arquivo local no mesmo computador.
  • Não vendemos, não compartilhamos e não usamos esses dados para publicidade.

Dados de visitantes deste site

Este site é estático e não usa cookies, formulários nem ferramentas de rastreamento. Ele é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso conforme a política do GitHub.

Dados de terceiros

O aplicativo não coleta dados de espectadores, seguidores ou de quem comenta nos vídeos, além dos totais agregados que as plataformas fornecem ao dono do canal.

Exclusão

O acesso do aplicativo pode ser revogado a qualquer momento nas configurações de cada plataforma. Revogado o acesso, os tokens guardados deixam de funcionar e são apagados. Para pedir a remoção de qualquer dado, escreva para jp.lourenco1998@gmail.com.

Plataformas

O uso das APIs segue as políticas de cada plataforma: Serviços de API do YouTube e a Política de Privacidade do Google (policies.google.com/privacy), Plataforma Meta e Termos da TikTok para desenvolvedores.
