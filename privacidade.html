Política de privacidade

Atualizada em 21 de outubro de 2026.

Esta política vale para o site Patrão Explica e para o aplicativo Publicador, usado pelo canal para publicar vídeos e consultar estatísticas nas plataformas YouTube, Instagram, Facebook e TikTok.

Quem usa o aplicativo

O Publicador é uma ferramenta de uso interno do canal. Ele é operado apenas pelo responsável pelo canal, nas contas do próprio canal. Não há cadastro de outras pessoas nem oferta do aplicativo ao público.

Quais dados são acessados

  • Identificação das contas do canal nas plataformas (nome, identificador, nome de usuário).
  • Credenciais de acesso (tokens) concedidas pelas plataformas por meio do login oficial de cada uma.
  • Vídeos, títulos, descrições e legendas que o canal decide publicar.
  • Estatísticas públicas e privadas dos vídeos do canal (visualizações, curtidas, comentários, retenção), para acompanhar o desempenho dos episódios.
  • Comentários feitos nos vídeos do canal (nome de usuário público e texto do comentário), para que o canal possa ler e responder. A resposta é sempre aprovada por uma pessoa antes de sair.

Como os dados são usados e guardados

  • Os dados são usados só para publicar os vídeos do canal e acompanhar os números deles.
  • Os tokens ficam guardados no cofre de credenciais do sistema operacional do computador do canal. Não são enviados a terceiros nem a nenhum servidor nosso.
  • As estatísticas ficam em um arquivo local no mesmo computador.
  • Não vendemos, não compartilhamos e não usamos esses dados para publicidade.

Dados de visitantes deste site

Este site não usa cookies. Para contar visitas usamos o GoatCounter, que não identifica pessoas: registra a página, o site de origem, país, tipo de aparelho e navegador, e cliques nos links das redes, sem guardar IP nem o e-mail digitado (política do GoatCounter). O site é hospedado no GitHub Pages, que pode registrar dados técnicos de acesso conforme a política do GitHub.

Lista de aviso do curso

Se você deixar seu e-mail no formulário da página inicial, guardamos o e-mail, junto com a data e o seu aceite, num Formulário Google ligado a uma planilha do responsável pelo canal. Usamos esses dados só para avisar quando o curso sair e mandar novidades dele. Não vendemos nem repassamos a ninguém.

Você pode sair da lista ou pedir para apagar seus dados a qualquer momento, escrevendo para jp.lourenco1998@gmail.com ou respondendo a qualquer mensagem nossa. Base legal: o seu consentimento (LGPD, art. 7º, I).

Dados de terceiros

Além dos comentários descritos acima, o aplicativo não coleta dados de espectadores ou seguidores: só os totais agregados que as plataformas fornecem ao dono do canal. Os comentários lidos ficam no computador do canal e são usados só para responder.

Exclusão

O acesso do aplicativo pode ser revogado a qualquer momento nas configurações de cada plataforma. Revogado o acesso, os tokens guardados deixam de funcionar e são apagados. Para pedir a remoção de qualquer dado, escreva para jp.lourenco1998@gmail.com.

Plataformas

O uso das APIs segue as políticas de cada plataforma: Serviços de API do YouTube e a Política de Privacidade do Google (policies.google.com/privacy), Plataforma Meta e Termos da TikTok para desenvolvedores.
